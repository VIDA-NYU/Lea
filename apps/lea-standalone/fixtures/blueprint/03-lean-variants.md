# Blueprint — Lean name variants

Each node spells its `lean:` (and `file:`) line differently; only the name is kept.

## a
- kind: lemma
- lean: `Lea.V.a` — file `A.lean`

A backtick span followed by a file phrase on the same line.

## b
- kind: lemma
- lean: Lea.V.b (the declaration)

A bare name followed by a parenthetical.

## c
- kind: theorem
- lean: `Lea.V.c`, in C.lean

A backtick span followed by a comma and more words.

## d
- kind: definition
- lean:

An empty lean value.

## e
- kind: lemma
- lean: Lea.V.e.
- file: E.lean (planned)

A bare name with a trailing period, and a bare file with a note.
